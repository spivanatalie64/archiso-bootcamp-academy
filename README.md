# ArchISO Bootcamp Academy

An online teaching environment with exactly one scope:

**Teaching people how to build Arch Linux ISO images, so they can build their own flavours.**

The format is the bootcamp shape -- short lesson, do the thing right there, get checked, move on. Not a general Linux course. Not a general programming course. ISO building, start to finish:

- what archiso is and how a profile is put together
- packages, pacman config, and the airootfs
- bootloaders and boot modes
- building with mkarchiso, and reading the errors when it breaks
- testing the ISO and fixing what the test shows
- turning the profile into your own flavour

A person who finishes should be able to build their own flavour from a blank profile -- not just follow a recipe.

## Hosting rule

Hosting stays **offsite and free**. The lessons live on static hosting, and the hands-on environments run on other people's free tiers, in the learner's browser or the learner's own account. Nothing here depends on a personal server staying up, and nobody has to pay for somebody else's lesson time.
